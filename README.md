# Files Manager

Файловый менеджер для Android с полным доступом к файловой системе устройства.
Данные хранятся только локально — приложение не обращается к сети.

## Возможности

**Работа с файлами**
- Навигация по внутренней памяти, съёмным носителям и системному корню (`/`)
- Копирование, перемещение, переименование, удаление, создание папок
- Сортировка по имени, дате и размеру
- Поиск по имени файла по всему устройству
- Просмотр текстовых файлов и изображений
- Создание и распаковка ZIP-архивов

**Приватность**
- Приватное хранилище: файлы шифруются AES-256-GCM, ключ хранится в Android
  Keystore и не покидает устройство. Исходный файл удаляется после шифрования;
  если удалить его не удалось, операция откатывается, чтобы незашифрованная
  копия не осталась на диске.
- Переключатель показа скрытых файлов
- Приложение не запрашивает разрешений, кроме доступа к файлам, и не имеет
  доступа в интернет

**Полный доступ**
- `MANAGE_EXTERNAL_STORAGE` для доступа ко всему хранилищу
- Опциональный root-доступ: если обычная файловая операция не проходит,
  выполняется через root-шелл (libsu)

## Требования

- Android 11 (API 30) и выше
- Root — опционально, только для файлов вне обычного доступа

## Сборка

```bash
./gradlew assembleDebug          # APK: app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest      # юнит-тесты
```

Готовый debug-APK каждой сборки публикуется в
[Releases](https://github.com/nonedeity-dotcom/Files_Manager/releases).

## Тесты

- **Юнит-тесты** (`app/src/test`) — экранирование путей для шелла, генерация
  неконфликтующих имён, ZIP (в том числе защита от Zip Slip). Запускаются в CI
  на каждый пуш.
- **E2E-тесты** (`.maestro/`) — сценарии Maestro: запуск и просмотр, создание/
  переименование/удаление папки, поиск, настройки и хранилище. Выполняются в CI
  на реальном Android-эмуляторе.

Locally Maestro flows can be run against a connected device:

```bash
maestro test .maestro/
```

## Архитектура

```
app/src/main/java/com/filemanager/app/
├── data/        репозитории: файловые операции, root-шелл, шифрование, настройки
├── domain/      модели: FileItem, SortOrder, результаты операций
├── ui/          экраны на Jetpack Compose + ViewModel'и
└── util/        экранирование для шелла, работа с путями, форматирование
```

Kotlin, Jetpack Compose, MVVM, корутины, DataStore.
